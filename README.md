# Nishchay Chauhan

Personal portfolio for Nishchay Chauhan, a software developer offering development and technical consultation. The site is a static Next.js app. The consultation button opens an email draft. There is no backend, database, or API key.

## Run locally

```bash
npm install
npm run dev
```

The dev server uses port 43123 when started with:

```bash
npm run dev -- --port 43123
```

`npm run dev` alone uses Next.js’s default port.

## Production

```bash
npm run lint
npm run build
npm start
```

Deploy on Vercel with the default Next.js settings. No extra configuration is required.

Set `NEXT_PUBLIC_SITE_URL` to the public origin (for example `https://example.com`) when you want canonical URLs and Open Graph metadata to use a custom domain. On Vercel, the production deployment URL is used when that variable is unset.
